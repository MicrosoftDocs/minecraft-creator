# Editor Action Bar

The Action Bar has quick functions like **undo** and **redo** that affect the things you do to the world, including some of the actions you can do in Crosshair Mode.

|Command |Shortcut |
|:-------|:-------|
| Undo | `Ctrl Z` |
| Redo | `Ctrl Y` |
| Attach Debugger | - |
| Input Mapping | - |
| Reload | - |
| Crosshair Mode| `Ctrl Tab` |


## How to add actions to the Action bar

Press the [+] on either the right or left side and choose the Action you want to add to the bar from the menu.
