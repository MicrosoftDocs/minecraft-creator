# Control Help

The Control Help panel displays the keyboard shortcuts that are available while you work in Tool mode. It shows general Editor controls and, when a tool is active, a separate list of controls for that tool. The displayed shortcuts reflect your current key bindings and update when you customize them.

## Open Control Help

You can open Control Help in any of these ways:

- Press **F1** while in Tool mode.
- Open the **Help** menu and select **Control Help**.
- Add **Control Help** to the Action Bar, and then select it there.

To add Control Help to the Action Bar:

1. Select the **+** button on either side of the Action Bar.
1. Select **Control Help**.

For more information about adding and removing Action Bar items, see [Editor Action Bar](EditorActionBar.md).

## Use Control Help

The **General Editor Controls** pane lists shortcuts that are available across Editor. When you activate a tool, a second pane displays the tool-specific controls.

> [!NOTE]
> Tool-specific controls require the viewport to be active. Select the viewport before using a listed shortcut if focus is currently in a property field or another panel.

Select the settings button in the tool-specific pane to open Keyboard Settings for the active tool. From there, you can change its shortcuts. For the complete shortcut list and information about custom key bindings, see [Editor Hotkeys](EditorKeyboardInputs.md).
