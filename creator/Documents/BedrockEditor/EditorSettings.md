# Editor Settings

Use **Settings** to adjust navigation, cursor behavior, interface appearance, sound, and world visualization while editing.

## Open Settings

There are two ways to open the Settings panel:
1. Select **File** > **Settings**.
2. Add **Settings** to the [Action Bar](EditorActionBar.md), and then select it there.

## Control

- **Move Speed Multiplier**: Adjusts navigation speed. The slider accepts whole numbers from 1 to 10. In the viewport, use **Shift+Q** to decrease the multiplier or **Shift+E** to increase it.
- **Project cursor through liquid**: Controls whether the cursor targets blocks through water or lava.

> [!NOTE]
> Tool Mode uses **E** to move up and **Q** to move down. The **Shift+E** and **Shift+Q** combinations adjust movement speed instead.

## Interface

- **Show Compass**: Shows or hides the directional compass.
- **Show Toast Notifications**: Shows or hides toast notifications.
- **Show Chat Window**: Shows or hides chat.
- **Mute Music**: Mutes music while editing.
- **Mute Game Sounds**: Mutes game sounds while editing.
- **UI Scale**: Changes the size of the Editor interface. Available scale options depend on the display.
- **Font**: Changes text size, from 50% to 200% in 25% increments.
- **Theme**: Selects an available Editor color theme.
- **Suppress New Content Badges**: Hides badges that identify new content.
- **Clear Content Badges**: Clears the current new-content badges.
- **Restore New Content Badges**: Restores new-content badges.

UI appearance controls are in **File** > **Settings** > **Interface**, not a separate File menu command.

## World View

- **Night Vision**: Makes dark areas easier to see while editing.
- **Render Clouds**: Shows or hides clouds in your editing view. This doesn't change project world data.
- **Show Invisible Blocks**: Displays supported blocks that are normally invisible.
- **Show Chunk Boundaries**: Shows boundaries between 16 x 16-block chunks.

## Keyboard and tool settings

Select **File** > **Keyboard Settings** to customize [keyboard shortcuts](EditorKeyboardInputs.md). Individual tools also have their own cursor and targeting controls.
