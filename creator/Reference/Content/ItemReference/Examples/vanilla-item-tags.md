# Vanilla Item Tags

This is a list of all Vanilla Item tags that can be added to an item using the [minecraft:tags](./ItemComponents/minecraft_tags.md) item component.

Creators can make their own tags if they wish. However, only Vanilla item tags can use the `"minecraft:"` namespace.

## Armor tags

| Name                        |
|-----------------------------|
| "minecraft:is_armor"        |
| "minecraft:horse\_armor"    |
| "minecraft:nautilus\_armor" |
| "minecraft:harness"         |
